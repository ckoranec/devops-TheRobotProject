GIS & Routing Infrastructure

This dashboard provides an overview of the data and scripts powering the robotic delivery routing engine for the George Mason University campus.

Campus GIS Data

File: html/data/gmu_map.json

This file contains the road network and sidewalk nodes extracted from OpenStreetMap. It serves as the base graph for the A* routing algorithm.

JSON Format
OSM Overpass API
{ "version": 0.6, "generator": "Overpass API", "elements": [ { "type": "way", "id": 8836894, "tags": { "highway": "service", "name": "Aquia Creek Lane" } }, ... ] }

GIS Update Utility

File: html/mapAPI.py

A Python-based utility script that connects to the Overpass API to fetch the latest campus geography. It handles the conversion of raw GIS data into the project's standardized JSON format.

Python 3
Requests Lib
import requests QUERY = """ [out:json][timeout:25]; way["highway"](38.830,-77.310,38.831,-77.309); out geom; """ # Fetches data and saves to html/data/gmu_map.json
